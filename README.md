# 🦀 Axum API
_______________________________________________________________________________

## Starting the server
_______________________________________________________________________________

Run this command to start the server
```bash
cargo dev
```
_______________________________________________________________________________

## API Testing
_______________________________________________________________________________

First enter the `api-testing` directory
```bash
cd api-testing
```
_______________________________________________________________________________

To make a request to specific route (E.g. A GET request to the `/` route)
```bash
hurl root_get.hurl
```
_______________________________________________________________________________

To test all routes in the `api-testing` directory
```bash
hurl --test *.hurl
```
_______________________________________________________________________________
